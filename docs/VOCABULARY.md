# 内置词库与分级说明

本项目内置 **100,000 个按英文拼写去重的英语词条**。原有「词汇花园」至「探索远方」六个主题的 54 个单词均包含在此总数内；界面继续使用这 54 个单词原来的词性、精选释义和双语例句，不额外重复计数。

这不是「十万个常用词」或「小学至大学官方必背词表」。英语基础学习只需要其中一部分；大学拓展包含低频词、学科术语、历史用语及部分独立收录的词形。词条经过自动筛选，未逐条人工校对，源词典的个别译法和标注可能不够现代或准确。

## 词性与释义

每个词条只选取一个有源词性标签的中文义项，供「英文 + 词性 + 含义」三牌配对。选取过程直接解析中文释义的词性段落，不根据词尾猜测词性，不把所有条目默认为名词，也不把不同词性段落的释义混用。

映射规则：`n.` → 名词；`v./vt./vi./aux.` → 动词；`a./adj.` → 形容词；`ad./adv.` → 副词；其余保留 `pron./prep./conj./num./art./interj.`。原始完整释义保留更细的标签，例如及物、非及物和助动词。

精选义项从源释义中提取，去掉方括号领域说明和圆括号注释后选取完整短语，不按字符硬截断。对 `can`、`still`、`like` 等常用多义词设置了少量入门优先义项，并在构建时检查这些义项确实属于源词条对应的词性段落。

筛选排除了数字、公式、缩略语标记、非字母拼写、已标注专名、过长释义、没有可靠词性和中文义项的条目，以及大多数仅指向词形变化的释义。小学精选词若另有独立词性义项可以保留，例如 `left` 的形容词义项。源数据仍可能含有未明确标记的专名、旧译或独立词形，不应视为人工精校教材。

## 六阶段学习路线

| 阶段 | 词条数 | 分配依据 |
| --- | ---: | --- |
| 小学基础 | 662 | 人工选择的生活、家庭、校园、颜色、数字、动物和基础功能词拼写，再从源数据提取义项 |
| 初中进阶 | 958 | 剩余 `zk` 标记词，以及未标注考试但词频序号 ≤ 1,500 的词 |
| 高中提升 | 3,109 | 剩余 `gk` 标记词，以及未标注考试但词频序号 ≤ 6,000 的词 |
| 大学四级 | 5,716 | 剩余 `cet4` 标记词，以及未标注考试但词频序号 ≤ 12,000 的词 |
| 大学六级 | 8,625 | 剩余 `cet6` 标记词，以及未标注考试但词频序号 ≤ 20,000 的词 |
| 大学拓展 | 80,930 | 剩余低频和专业词条，包含缺少词频的词条 |
| 合计 | **100,000** | 不重复计数 |

重叠标签按小学、初中、高中、四级、六级的顺序分配一次。无考试标签时，取 `bnc` 和 `frq` 中非零的较小值用于自动分级；同一阶段按词频排序。没有词频的条目按拼写长度、再按字母排序，这是排序启发式，不是科学测量的难度分数。游戏再通过每关词数、记忆时间和叠层规则增加挑战。

上述阶段是游戏学习路线，**不是教育部门课程标准，也不是对当前考试大纲完整性、释义准确性或年龄适宜性的保证**。考试标签来自固定版本词典，尚未逐条与最新大纲核对。

## 数据规模与加载

- 实际唯一英文拼写：100,000；全部为纯字母单个词条，未用短语、数字或重复记录补足数量。
- 有源音标：90,497；有源词频：39,162。
- 通过筛选的候选词条：104,983，从中保留所有基础/考试/原主题词，再按排序选满 100,000。
- `public/vocabulary/manifest.json` 保存各阶段词数、分片偏移、字节数和 SHA-256。
- 每个内容分片最多 2,000 条，且小于 880,000 字节；数据按阶段和关卡需要加载。
- `lookup-a.json` 至 `lookup-z.json` 是按首字母拆分的定位索引。小写拼写映射到 `[阶段索引, 分片索引, 分片内行号]`，方便刷新后直接找回收藏和学习记录。
- TypeScript 数据约定见 `src/data/librarySchema.ts`。词条 ID 为 `dict:` 加小写拼写；原主题条目由应用按拼写覆盖回原 ID，保留既有学习进度。
- 词条中的 `definition` 是完整中文释义；`meaning` 是本轮使用的单个简短义项。空的 `example`/`exampleZh` 表示源数据没有提供例句。

## 可复现构建与校验

仅需 Python 3 标准库，在仓库根目录运行：

```sh
python3 scripts/build-vocabulary.py
```

脚本从固定 revision 下载 CSV 至已被 Git 忽略的 `output/vocabulary-source/`，校验输入哈希后生成分片。若已有源文件，可使用：

```sh
python3 scripts/build-vocabulary.py --source /absolute/path/to/ecdict.csv
```

只验证已提交产物，无需联网、下载或修改任何文件：

```sh
python3 scripts/build-vocabulary.py --check
```

校验包括：准确 100,000 个唯一 ID/拼写；完整覆盖原 54 词；每条有中文和源词性匹配的精选义项；阶段词数、排序和偏移一致；分片内容哈希和字节数一致；全部定位索引指向正确词条。

词库由固定输入和确定性规则生成，产物不包含构建时间。修改筛选、分级或选义规则后需要重新构建全部词库并更新本文计数。
