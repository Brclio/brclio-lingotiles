# LingoTiles · 词了个词

响应式英语记忆与叠层消除游戏，React + TypeScript + Vite。内置 10 万词，保留原六个主题，并提供小学至大学的分级闯关、逐次通关记录和胜利特效。无需账号与后端。

## 本地运行

使用 Node.js 22.18+（或 Node.js 24/26）和 npm：

```sh
npm install
npm run dev
```

打开终端显示的本地网址。生产文件通过 `npm run build` 输出到 `dist/`；使用 `npm run preview` 预览。Vite 使用相对资源路径，可以将 `dist/` 托管在普通静态站点或 GitHub Pages 子目录。生产文件需要 HTTP 服务，不建议通过双击 HTML 的 `file://` 协议打开。

```sh
npm test
npm run build
```

## 玩法

1. 选择「经典主题」或「分级闯关」。经典主题保留「词汇花园」「日常小事」「城市漫游」「心情调色盘」「灵感工作室」「探索远方」六关、54 个精选词及原双语例句，记忆时间可选 30 / 60 / 90 秒。分级模式可选择阶段、上一关、下一关或跳转指定关号，使用本阶段标准记忆时间，也可增加 30 或 60 秒。
2. 点击「开始记忆」后，展示本关完整词表、词性、中文释义和音标。支持浏览器英语朗读。倒计时结束自动开始，也可以提前进入游戏。
3. 点击未被遮挡的卡牌放进七格暂存槽。英文、对应中文释义和词性三张自动消除；同词性牌和完全相同的中文含义牌通用。先执行匹配，再判断七格满槽失败。
4. 清空所有卡牌通关；满槽无匹配则可用剩余撤回恢复，或重新记忆。每组 100 分，每次辅助扣 30 分。无辅助 3 星、1–2 次辅助 2 星、更多 1 星。消除阶段不设超时惩罚。
5. 每局提供三次撤回、两次提示、两次洗牌。撤回只作用于最后一张未消除牌。无法安全提示或洗牌时不消耗道具。洗牌保持暂存槽内容；成功消除后不可撤回。
6. 词表记忆结束后加入「已复习」。通关保存最佳成绩，同时为本次成功新增一条完整用时记录，并播放有限时长的庆祝特效。可在单词本分页浏览 10 万词，按阶段筛选、搜索英文或中文、听发音、收藏和展开完整释义；原主题词仍显示双语例句，没有源例句或音标时不补造内容。

## 分级词库

| 阶段 | 去重后的词条数 | 每关最多词数 | 标准记忆时间 |
| --- | ---: | ---: | ---: |
| 小学基础 | 662 | 6 | 90 秒 |
| 初中进阶 | 958 | 8 | 80 秒 |
| 高中提升 | 3,109 | 10 | 75 秒 |
| 大学四级 | 5,716 | 12 | 70 秒 |
| 大学六级 | 8,625 | 14 | 65 秒 |
| 大学拓展 | 80,930 | 16 | 60 秒 |
| 合计 | **100,000** | — | — |

阶段末关使用剩余词条，不通过重复词条补满。更高阶段使用更多词、更少的每词标准记忆时间和更多叠层卡牌。用户可以直接选择阶段和关号，无需先通关全部前置内容。

小学使用人工选择的基础拼写，其余阶段参考 ECDICT 的考试标签和词频自动分配；分级是游戏学习路线，并非官方课程标准、教材或考试大纲。大学拓展包含专业词和低频词。原 54 词包含在 100,000 总数内，加载时按英文拼写覆盖为原主题 ID、精选义项和例句，保留既有收藏与学习进度。

词库由固定 revision 的 ECDICT 构建，随包分发 MIT 原始许可证。内容分为 53 个 JSON 分片，每个最多 2,000 条，并有 manifest 和 26 个首字母定位索引。关卡和普通词表页面只读取当前所需分片；收藏与已复习列表通过定位索引读取词条。搜索按分片扫描选定范围，显示检索进度并支持取消，首次全库搜索可能读取全部分片。单词本每页呈现 36 条，避免同时渲染 10 万行。

来源、清洗规则、自动分级依据、输入哈希与重建步骤见 [VOCABULARY.md](VOCABULARY.md)。可使用以下命令独立检查提交的词库产物，无需下载源文件：

```sh
python3 scripts/build-vocabulary.py --check
```

## 状态和时间

- 记忆阶段以真实截止时间计时；切换浏览器标签不能重置计时。查看游戏说明或离开确认时暂停，关闭后继续。
- 游戏暂停会隐藏整个棋盘和槽位；暂停及对话框时间不计入游戏用时。
- 消除用时在结束时固定，记忆用时记录本次实际使用的记忆时长，合计为两者之和。记录保留秒的小数，界面显示分秒；用时排除暂停和相应对话框停留。
- `localStorage` 中的 `lingotiles.progress.v1` 继续保存已复习单词、收藏、关卡最佳成绩和连续学习天数。词库尚未加载时，也保留有效的词典词条 ID。刷新会重置正在进行的局面。
- 逐次通关记录存入 IndexedDB 数据库 `lingotiles.history.v1` 的 `completions` 表。每次尝试使用独立 ID，重复完成回调按 ID 去重，重新练习成功则新增一条；不会因为只保留最佳成绩而覆盖历史，也不按固定记录数量截断。记录数量仍受浏览器存储空间影响。
- 「通关足迹」按完成时间倒序分页显示，提供最近、最快用时和完整 CSV 导出。每条包含完成时间、模式、关卡及阶段、词数、消除用时、记忆用时、合计用时、得分、星级和道具次数。最快用时包含使用道具的记录，不同关卡难度和词数不同，用时只作学习参考。
- 旧版本只有最佳成绩与练习次数的汇总，无法还原当时的每一次通关；界面保留原汇总，但不会伪造历史明细。
- 存储失败时游戏可继续：词汇进度在页脚提示，逐次记录标明仅临时保存在本页并可导出 CSV。当前浏览器清除网站数据后记录会丢失；没有云同步。
- 朗读使用设备的 Web Speech API，是否可用取决于浏览器及其英语语音支持。应用没有额外语音服务、账号或统计请求。

## 通关特效

通关成功后使用 Canvas 播放约 2.6 秒的彩纸与星星动画，每次发射 66 个粒子；星星数量对应本局星级。覆盖层设置 `pointer-events: none`，不遮挡复盘按钮的操作，动画结束或组件卸载后停止 `requestAnimationFrame`。开启 `prefers-reduced-motion: reduce` 时不启动粒子动画，改为静态成功文字和星星；运行期间偏好变更也会停止动态效果。

## 代码

- `src/data/vocabulary.ts`：保留的 6 关、54 个词和双语例句，以及兼容扩展词性的游戏词条类型。
- `src/data/library.ts`：六阶段参数、词库分片与定位索引读取、主题词覆盖、分页搜索和按关加载。
- `src/data/librarySchema.ts`：生成词库与 manifest 的数据约定；`public/vocabulary/` 保存随站点分发的实际词库。
- `scripts/build-vocabulary.py`：下载固定版本源数据、校验哈希、确定性生成词库及检查产物。
- `src/game/engine.ts`：纯函数引擎，坐标遮挡、通用词性匹配、确定性随机牌局、撤回、提示、洗牌。桌面采用 6×4 坐标布局，手机新局采用 4×5 宽牌布局以保留完整英文拼写。初始牌局按可点击的位置序列构造，提供可验证的解法。用户自行取牌后仍可能进入无解状态。
- `src/game/progress.ts`：验证本地学习进度、最佳成绩及连续学习天数。
- `src/game/history.ts`：逐次通关记录的校验、IndexedDB 存储、幂等写入、分页查询、汇总和 CSV 导出。
- `src/App.tsx`：主题与分级模式、记忆、消除、复盘、精确阶段用时和历史保存状态。
- `src/components/CurriculumPicker.tsx`、`VocabularyNotebook.tsx`：学习阶段与关号选择，以及词库分页、过滤和检索。
- `src/components/HistoryPanel.tsx`、`VictoryCelebration.tsx`：通关足迹和有限时长庆祝效果。
- `src/styles.css`、`src/curriculum.css` 及组件样式：桌面、平板、移动端布局，键盘焦点与减少动态效果支持。

测试文件覆盖匹配与遮挡、共享词性及同义牌、七格边界、较大词表的可解牌局、词库分页与搜索、旧词覆盖、历史追加与去重、存储失败、CSV 转义和连续天数边界。具体执行结果及浏览器检查见 [VERIFICATION.md](VERIFICATION.md)。
